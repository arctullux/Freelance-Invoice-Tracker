# Freelance Invoice Tracker

## General Information
This is a simple invoice and payment tracker that will store client information in a local database file, and will retrieve information upon request.
**This database is not secured. In this stage, do not input sensitive information into the database. Files are unencrypted and can be accessed by unauthorized actors.**


## Technologies & Dependencies
This repository will use Python and sqlite. 
### Dependencies
No dependencies are required.
